# 慢慢来

手机 App / 小程序风格的教程陪做网页原型。

## 本地运行

使用 Node.js 18 或更新版本，无需安装依赖。以下命令都在本目录（`frontend/`）中执行。

1. 在仓库根目录把 `.env.example` 复制为 `.env`（前后端共用）。
2. 在其中填写自己的 OpenRouter API 密钥，勿提交密钥。
3. 先按仓库根目录 README 启动 FastAPI 后端（默认 `http://127.0.0.1:8000`）。
4. 运行 `node server.cjs`。
5. 打开 http://127.0.0.1:8766/。

`server.cjs` 通过 `__dirname` 定位 `dist/index.html`，并从上一级目录（仓库根目录）读取 `.env`。

## 当前功能

- 聊天首页、点击推荐问题直接发送。
- 用户提出问题时，由聊天服务调用 FastAPI，在 YouTube 实时检索相关教程。
- 点击检索结果会在当前页弹窗播放 YouTube 原视频；点击“教程分解”后才创建下载任务并进入独立页面。
- 下载页会在下载期间继续播放 YouTube，完成后自动切换为本地 MP4。
- 视频拆解页可根据真实字幕或粘贴的教程文字生成分步骤 SOP，包括工具、操作、完成标准、易错点、补救建议和静态安全提示。
- 每步可回看字幕时间点、提取本地视频参考帧；支持编辑步骤、浏览器保存与 JSON 导入导出。
- 首页可打开人工编写的缝纽扣 SOP 示例，无需请求模型。
- 使用 OpenRouter 的 `inclusionai/ling-3.0-flash-sante:free` 进行文字对话，无付费回退。
- 本地视频预览，视频不会上传服务器。

## 原型限制

YouTube 结果来自实时检索；点击“教程分解”后才会下载到本机。SOP 根据字幕/文字整理，尚未接入视频视觉分析或无字幕视频的音频转写。参考帧从本地视频提取，需核对是否对应动作。视频拆解不包含打卡或新手引导。免费模型可能受限流影响。

服务只监听本机地址；部署为公开服务前需添加用户认证、请求限额及服务端密钥管理。
