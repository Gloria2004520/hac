# 慢慢来

手机 App / 小程序风格的教程陪做网页原型。

## 本地运行

使用 Node.js 18 或更新版本，无需安装依赖。

1. 将 `.env.example` 复制为 `.env.openrouter.local`。
2. 在本地文件中填写自己的 OpenRouter API 密钥，勿提交密钥。
3. 运行 `node server.cjs`。
4. 打开 http://127.0.0.1:8766/。

## 当前功能

- 聊天首页、点击推荐问题直接发送。
- 绿植教程按水培、小盆栽、大盆栽分类，提供人工精选的真实视频链接。
- 点击视频卡片在弹窗中预览，再选择解析步骤。
- 使用 OpenRouter 的 `inclusionai/ling-3.0-flash-sante:free` 进行文字对话，无付费回退。
- 本地视频预览，视频不会上传服务器。

## 原型限制

视频列表不是实时检索。内嵌播放受视频平台限制，提供原视频链接作为备用入口。步骤解析和检查尚未接入真实视频理解，当前步骤为明确标注的通用演示。免费模型可能受限流影响。

服务只监听本机地址；部署为公开服务前需添加用户认证、请求限额及服务端密钥管理。
